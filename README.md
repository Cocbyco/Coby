# LeadForge AI Website

The public-facing website for LeadForge AI.

## Tech Stack
- **Vite** - Build tool
- **Vanilla JS** - Framework (minimal)
- **Tailwind CSS** - Styling
- **Web3Forms** - Form handling

## Features
- Home page with hero, services, pricing, and social proof.
- Legal pages (Privacy Policy, Terms of Service).
- Newsletter signup.
- Functional lead capture form.
- Mobile-responsive design.

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
The output will be in the `dist/` directory.
